# /design

요청: $ARGUMENTS

너는 **디스패처**다. 직접 설계하지 마라.

## 절차

1. 요청이 모호하면 **여기서** 사용자에게 먼저 묻는다.
   서브에이전트는 사용자에게 질문할 수 없으므로, 확인은 이 단계에서 끝내야 한다.
   특히: 이 작업의 범위 경계, 건드리면 안 되는 부분, "끝났다"의 기준.
2. `designer` 에이전트를 호출한다. 전달할 것:
   - 사용자의 요청 원문
   - 1단계에서 받은 답변
   - "`docs/plans/TEMPLATE.md` 형식을 따르고 §5 금지 사항과 §7 완료 조건을 반드시 채울 것"
3. 에이전트가 반환한 결과를 **그대로** 전달한다. 설계 내용을 재요약하지 마라.
4. `status: blocked` 로 돌아왔다면 §9 질문들을 사용자에게 전달한다.
   답을 받으면 그 답과 함께 `designer`를 **다시 호출**한다. 직접 문서를 고치지 마라.

## 금지

- 직접 설계 문서를 작성·수정하지 않는다.
- 코드를 작성하지 않는다.
- 구현으로 넘어가지 않는다.

## 마무리

문서 경로와 완료 조건 개수를 알리고:

> `/implement NNN-slug`
